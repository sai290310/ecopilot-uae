# EcoPilot UAE

A premium dark-mode building sustainability and rooftop solar planning demo built with React, TypeScript, Vite, and Three.js.

## Included in the current foundation

- Five connected sections: Dashboard, Building Studio, Solar Planner, Analysis, Final Report
- Shared assessment state across all views
- Demo UAE school project using the same state and calculation logic
- Deterministic solar calculation module
- 2D roof planner with dimensions and candidate zone controls
- 3D model viewer placeholder and upload handling
- Financial analysis block and print-ready report
- Futuristic dark UI styling inspired by premium simulation dashboards

## Run locally

1. Install dependencies:
   npm install

2. Start the app:
   npm run dev

3. Open the local URL shown by Vite, usually:
   http://localhost:5173

## Production build

npm run build

## Notes

This project is an initial working foundation for the EcoPilot UAE concept. It is designed as a polished demo/prototype and can be expanded with more advanced GLB upload parsing, richer roof-surface interaction, charting, and more robust validation.
